Open Grips

Prometheus / Sisyphus measurement customizer

Enter finger measurements, review the computed offsets, and download an experimental printable STL generated in your browser.

Important status

This GitHub Pages version is a client-side parametric rebuild based on the formulas in the repository README. It does not directly edit the STEP solids; GitHub Pages is static and cannot run FreeCAD/OpenCascade server-side.

Use generated STLs as experimental fit prototypes. For production-quality matching to the STEP files, the next step is a FreeCAD/CadQuery backend or a full parametric CAD rebuild.
