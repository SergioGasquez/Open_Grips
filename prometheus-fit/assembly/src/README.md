# Parts

How to put together a printed Prometheus grip, such as
`prometheus-fit/examples/right-hand/prometheus_right_A1.3mf`. The pictures show that right-hand grip; a
left-hand grip is its mirror image and goes together the same way.

You need the 14 printed parts, a cord for the anchor, and a mallet or hammer with a small wood
block.

The middle and index walls look alike: label them as you take them off the plate (the slicer's
object list names every part).

| Part | | How to recognize it |
|---|---|---|
| Frame | ![Frame](images/frame.png) | The largest part, with the top crossbar and the cord hole |
| Ring wall | ![Ring wall](images/ring_wall.png) | Round hump around a pin hole |
| Middle wall | ![Middle wall](images/middle_wall.png) | Looks like the index wall |
| Index wall | ![Index wall](images/index_wall.png) | Looks like the middle wall |
| End wall | ![End wall](images/end_wall.png) | Thin plate engraved `crimpdeq.com` |
| Pinky roller | ![Pinky roller](images/pinky_roller.png) | 30 mm, one narrow and one wide end |
| Ring, middle and index rollers (3) | ![Roller](images/ring_roller.png) | 19 mm, both ends the same |
| Pinky pin | ![Pinky pin](images/pinky_pin.png) | The longer pin, about 36 mm |
| Ring, middle and index pins (3) | ![Pin](images/ring_pin.png) | About 25 mm, interchangeable |
| Post | ![Post](images/post.png) | Long square bar, about 105 mm, one corner chamfered |

The illustrations come from the OpenSCAD model; regenerate them with `./render.sh`.
